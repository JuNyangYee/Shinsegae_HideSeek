# Shinsegae_HideSeek

mmWave 센서로 관객이 가까워지면 캐릭터가 숨고, 멀어지면 다시 나오는 웹 기반 숨바꼭질 체험(시퀀스 기반 연출) 프로젝트입니다.

현재(2026-10-20)는 **1단계 모의 입력 프로토타입**입니다. 페이지의 모의 거리 입력으로 근접 판정 → 숨기·등장 흐름을 확인합니다. **실제 센서 연동과 최종 영상·아트는 아직 없습니다.** 화면의 캐릭터·무대는 CSS로 만든 임시 더미입니다.

## 실행

- 필요: Node.js 24 이상. 외부 패키지가 없어 `npm install`은 필요 없습니다.

```sh
npm start        # http://127.0.0.1:8091/display/ (루트 / 는 이 주소로 이동)
npm test         # 근접 판정·시퀀스 상태 단위 테스트(node:test)
```

- 포트 변경: `PORT=8092 npm start` (PowerShell: `$env:PORT=8092; npm start`). `PORT=0`이면 빈 포트를 자동으로 고르고 실제 주소를 출력합니다.
- 서버는 `127.0.0.1`에서 `public/` 폴더만 제공합니다.

## 화면 조작 (개발용)

| 조작 | 동작 |
|---|---|
| 거리 슬라이더, `가까이`/`멀리` 버튼, `N`/`F` 키 | 모의 관객 거리 변경(가까이 0.8 m, 멀리 3.0 m) |
| `감지 없음` | 센서는 정상이지만 대상이 없는 샘플을 보냄 |
| `입력 오류` | 오류 샘플을 보냄 → 판정 unknown, 캐릭터는 숨은 상태로 안전 대기 |
| `전송 중단` | 샘플을 완전히 끊음 → 1.2초 뒤 끊김(stale) 처리 |
| `정상 입력 재개` | 정상 감지로 돌리고 전송을 다시 시작 |
| `D` 키 / `진단` 제목 | 진단 영역 펼침·접힘 |

시작하면 캐릭터는 숨어 있다가, 기본 거리 3 m가 0.6초 이어지면 처음 등장합니다. 거리·유지 시간·연출 길이는 모두 **임시값**이며 `public/display/config/settings.js` 한 곳에 있습니다.
