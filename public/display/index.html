개발 패널

입력 선택

-

센서 연결

-

거리는 센서까지의 거리(설치 높이·기울기 영향)입니다. 판정은 안정화 거리로 합니다. 설정 명령 처리 중·연결 끊김·거리 모드 아님·무수신은 안전 정지(H)입니다.

앱 판정 설정

-

센서 자체 설정

누를 때만 보드 펌웨어의 고정 명령(cmd setRange · setThrFactor · setMicroMotion · mode 1)을 차례로 보냅니다. 처리 동안 판정은 안전 정지합니다. 서버 시작·연결 때 자동으로 보내지 않습니다.

모의 입력 -

숫자 1/2/3은 실센서 중에도 모의 입력으로 바꿔 0.4/0.9/1.6 m 고정 거리를 정상 감지로 보냅니다(센서 연결·설정은 그대로, 패널이 닫혀 있어도 동작). 기본 경계에서 가까이/중간/멀리이며, 경계를 바꾸면 판정이 달라질 수 있습니다.

입력 상태: -

감지 없음은 대상이 없는 정상 샘플(= 원거리, 기본 놀이)입니다. 입력 오류·전송 중단은 안전 정지(H)로 갑니다.

화면

단축키: O 유화 · D 패널 표시 전환(항상) · 1 가까이 · 2 중간 · 3 멀리(항상 — 실센서 중이면 모의 입력으로 전환) · N 가까이 · M 중간 · F 멀리(모의 입력일 때만). 주소에 ?debug=1을 붙이면 패널이 열린 채 시작합니다.
